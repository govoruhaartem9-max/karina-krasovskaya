# KRASOVSKAYA PMU BROWS — сайт майстра

Односторінковий адаптивний сайт українською для Каріни Krasovskaya, майстра брів і перманентного макіяжу в Кам’янському.

## Перегляд

Відкрийте `index.html` у браузері. Сайт статичний, без збірки та залежностей.

## Структура

- `index.html` — сайт
- `logo.svg` — масштабований векторний логотип із прозорим фоном
- `logo.png` — наданий оригінал логотипа
- `PROMPT.md` — вихідний опис і вимоги до сайту

Ціни, точна адреса, відгуки та фото робіт не вигадані; їх можна додати після отримання матеріалів.
