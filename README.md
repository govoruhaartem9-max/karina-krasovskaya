# KRASOVSKAYA PMU BROWS — сайт майстра

Односторінковий адаптивний сайт українською мовою для Каріни Krasovskaya, майстра брів та перманентного макіяжу в Кам’янському.

## Перегляд

Відкрийте `index.html` у браузері. Сайт статичний, без збірки та залежностей. Логотип розташовано у `logo.jpg`.

## Перед публікацією

- За потреби додайте фактичні ціни й адресу кабінету.
- Замініть карту центру на точну мітку кабінету після отримання адреси.
- Фото до/після та відгуки не вигадані й не додавалися; їх можна додати, коли будуть матеріали.

## Структура

- `index.html` — сайт
- `logo.jpg` — логотип, наданий замовницею
- `PROMPT.md` — вихідний опис і вимоги до сайту
